    Methodology & Code

    Geocoding

    Each query is sent to the Nominatim API as <query>, India with countrycodes=in. Latitude, longitude, suburb, city, and state are extracted from the response.

    Price lookup

    The locality name is fuzzy-matched against india_house_prices.csv. If no row is found, the city base price from city_price_anchors.csv is multiplied by a seeded factor between 0.75 and 1.35.

    price_per_sqft = base_price_per_sqft * (0.75 + md5(locality) mod 1 * 0.60)

    K-Means tier clustering

    Property prices are clustered into three groups using KMeans(n_clusters=3). Clusters are labeled by ascending centroid price: Budget, Mid-Tier, Luxury.

    Historical back-derivation

    Historical prices are computed by discounting the current price with a per-locality growth rate.

    price(year) = price_now / (1 + g)^(current_year - year)

    Forecast

    A linear regression is fit on the four historical points and projected forward.

    Evaluation

    R squared, RMSE, MAE, and MAPE are computed from the linear regression residuals.

    Live geometry

    Overpass API fetches buildings, residential land plots, and nearby place nodes within 5 km. The query uses out center 200;. If Overpass fails, synthetic coordinates are generated so the map is never empty.
